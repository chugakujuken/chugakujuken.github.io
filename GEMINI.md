# Gemini CLI Instructions for this Project

This file contains specific instructions and preferences for the Gemini CLI when working on this project.

## General Guidelines:
- **No Commits Without Permission**: DO NOT commit any code changes without explicit user permission. Always ask for confirmation before initiating a commit.

## Project-Specific Preferences:
- **Educational Content**: When creating educational games or features, prioritize content relevant to "中学受験" (junior high school entrance exams). This includes using appropriate topics, Japanese names, and classifications (e.g., 哺乳類, 両生類, 爬虫類, etc.) as demonstrated in the animal matching game.
- **External Libraries**: For external JavaScript libraries like Phaser, prefer using CDN links for integration unless a specific build system (e.g., npm, Webpack) is explicitly set up and configured for the relevant project subdirectory.
- **Image/Asset Handling**: When images or assets are required for features (e.g., game sprites), prefer using publicly available URLs (like Twemoji SVGs) or generating placeholders. If custom images are needed, inform the user about the need and how they can replace placeholders.
